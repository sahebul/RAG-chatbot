External Portal Integration with RTPS
1.0 Purpose:
The purpose of this document is to define the external portal integration framework with RTPS
portal. This document describes the various APIs along with the necessary request and
response parameters required for integration.
1.1 Workflow:
The process flow of the application submission is as below.
1. The users of the RTPS portal will log into the RTPS portal.
2. Upon clicking the service link, the user gets redirected to the external portal where the
external portal will render the application form.
3. Once form submission is completed, the external portal redirects the user back to the
RTPS portal.
4. RTPS portal generates an acknowledgement along with the RTPS (application
reference) number.
5. In cases where the application submission process gets aborted
before completion, the external portal should be able to take back
the applicant to the earlier stage where the application was left
incomplete.
